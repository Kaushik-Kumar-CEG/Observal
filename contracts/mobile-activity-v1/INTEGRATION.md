**Backend arithmetic decision:** Author and User readings are separate distinct `(actor, verified run-incarnation)` root unions after event-time provenance and current visibility filtering. A root used by two components contributes one to each component row but only one to the person union. Forty attributable calls on one verified root contribute **one** trace. A verified **unprompted** root with attributable activity contributes a component trace but never a general prompted session. A missing or ambiguous parent link, reused legacy session ID or absent run-origin proof contributes no verified trace. Counts are partial or unavailable until all relevant kinds are qualified; installed components, generic sessions and usage pings are not substitute evidence. Unsupported zero is never a measured zero. A tool-free, root-witnessed, uploader-bound v2 Pi source with an approved, currently public MCP mapping can produce **self User partial zero**, rechecked against retained ClickHouse source and current approval; this is only an MCP subset, never a full-window, Author, general-session, skill or hook zero. Missing, repaired, parented, ambiguous, unsupported or over-budget sources remain unavailable. The Pi sender supplies a scoped collision fence and prospective lifecycle claim, **not independent run-origin attestation**; the trace headline capability remains off.
